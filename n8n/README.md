# Uttera en n8n

Los **flujos de ejemplo** de Uttera para n8n viven aquí (`flujos/`).

El **nodo de comunidad** (`n8n-nodes-uttera`) se ha movido a su **propio
repositorio**, que es su única fuente de verdad:

- Repo: https://github.com/uttera/n8n-nodes-uttera
- npm:  https://www.npmjs.com/package/n8n-nodes-uttera

Se separó porque la verificación de n8n espera el nodo en la raíz de su repo
(no encuentra la credencial en una subcarpeta de un monorepo).
